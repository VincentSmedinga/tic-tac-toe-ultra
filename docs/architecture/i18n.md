# Languages and texts

Read this before adding or changing a text, a language or a date.
The decisions are in [docs/plan.md](../plan.md), Languages.

- Players see Dutch (written first), English or Frisian, from the dictionaries in `src/i18n/`; a component never contains a text.
- `nl.ts` holds the keys (`as const`, plain texts and plural texts with `{placeholders}`). `en.ts` and `fy.ts` have exactly the same keys. `types.ts` makes `t('key', { values })` type-safe.
- A text goes in all three dictionaries at once. The compiler and `dictionaries.test.ts` insist.
- `useText()` (in `store.ts`) gives `t` in the language of the page; `useFormat()` (`format.ts`) the dates, lists, percentages and weekdays; `<Rich>` a text with an element in it.
- `useShapeNames()` (`shapes/names.ts`) and `usePlayerNames()` (`play/players.ts`) give the names of shapes and players.
- A component never builds a sentence from pieces. A text with a name or number is one sentence with `{placeholders}`.
- A function outside a component takes `t` as a parameter, like `fieldLabel(t, field)`.
- Names that people typed are never translated.
- The server only sends codes; the app has the words (`problem.*`).
- The addresses stay Dutch for every language.
- The language is chosen per device (`language.ts`: the registry `LANGUAGES`, `readLanguage`, which follows the browser the first time) and set on `<html lang>` and `dir` by `applyLanguage` in `store.ts`.
- `public/appearance.js` does the same before the first paint. `language.test.ts` runs it and compares.
- A language is only offered once somebody who speaks it has read it: `reviewed` in `LANGUAGES` and in `public/appearance.js`. `?alle-talen` on any address shows them all.
- Every screen has component tests in English and Frisian. `dutchLeaks` (`src/i18n/testing.ts`) fails when a Dutch text is on a screen that isn't Dutch.
- The tests start in Dutch (`src/test/setup.ts`); a story or test that needs another language calls `setLanguage('en')`.
- `e2e/languages.spec.ts` plays with two browsers in two languages.
- Adding a language is a line in `LANGUAGES`, a dictionary, the title in `appearance.js` and the offline texts in `public/offline.html`; see docs/plan.md, Languages.
